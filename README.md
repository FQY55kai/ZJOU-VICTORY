# GTA VI (Xbox) PC 移植包 — scarlett-fox 通用版

> 版本：**scarlett-fox-通用-2611272120**（2026-11-27 20:13 构建）
> 分支：`Op-lite/victory-scarlett` @ `scarlett-fox`（commit `bc264a4`）
> 目标：让 **8GB / 12GB / 16GB+** 显存的 N 卡用户都能跑起来，开箱即用

---

## 这是什么

把 **Xbox 版 GTA VI（`GTA6.Xbox.v1.0.2.1` dump）** 通过 `victory` 兼容层在 Windows PC 上运行的整合包。
本包基于 scarlett-fox 分支最新源码自行编译，包含：

- 上游 3 项修复：冻结修复（SOFT_VIEWS 页映射）、启动器着色器预翻译、默认画面修复（关 RT 无紫色植被）
- **多显存档位**（8/12/16GB+ 自动检测）
- **缓存/存档物理隔离**，从根源杜绝跨分支污染（紫边、模型乱闪）
- **自由模式存档跑图 → 预热 → 删档留缓存** 的标准化流程
- 每一步的说明横幅 + 读秒（按 T 跳过）+ 10 分钟自动跑图 + 黑匣子日志

## 环境要求

| 项目 | 要求 |
|---|---|

| 内存 | 16GB 起步（游戏常驻约 10-17GB，32GB 无压力） |

## 快速开始（5 步，严格按文件名数字顺序）

```
① 1-设置游戏路径（运行一次就行）.cmd   弹窗选游戏文件夹
② 2-启动前检查（运行一次就行）.cmd     查进程/校验exe/彻底清缓存（含本版）
③ 3-第一次启动（运行一次就行）.cmd     装自由模式存档 → 翻译着色器 → 自动跑图 10 分钟
④ 4-预热着色器（运行一次就行）.cmd     预热全部管线 → 删存档，缓存保留
⑤ 5-正常启动（之后一直用这个启动）.cmd 日常启动
```

> 首次 ①→⑤ 全走一遍；之后每天只双击 **⑤**。

### 各步骤细节

**① 1-启动前检查.cmd**
- 横幅说明停留 10 秒（按 `T` 跳过读秒）
- 5 项检查：残留进程 → exe SHA256 → 缓存清理（共享缓存 / NVIDIA 分叉缓存 / 本版专用缓存，有就删）→ 游戏目录 → 预热状态
- 任何一项不过都会停下并给出处理提示

**② 2-第一次启动.cmd**
- 横幅说明停留 20 秒（按 `T` 跳过）
- 自动装入 `zz-freeroam-save\` 里的自由模式存档（旧档自动备份为 `saves.backup`）
- 翻译标题全部着色器（**5-20 分钟窗口无响应属正常，切勿关闭**）
- 自动启动游戏，**10 分钟后自动关闭进程**，期间用过的 pipeline 全部记录进账本
- 游戏内**白屏 / 渲染错误 / 卡顿全部是正常现象**，不要关游戏，让它慢慢调用 pipeline，会一点点变好

**③ 3-预热着色器.cmd**
- `warm --used` 按账本逐条预编译管线（窗口不动属正常）
- 完成后**删除自由模式存档**（下次开新游戏），**着色器缓存 + 管线缓存全部保留**

**④ 4-正常启动.cmd**
- 直接启动，开新档玩。这是以后每天用的入口。

## 怎么改游戏路径

**推荐：双击 `设置游戏路径.cmd`**，会弹出文件夹选择框，选中包含 `game_scarlett_master.exe` 的文件夹即可。
它会校验文件存在，然后写入 `_game-path.cmd`——四个步骤脚本都读这一个文件，改一处全生效。

手动改也可以：编辑 `_game-path.cmd`，把这一行改成你的路径（不要带结尾反斜杠）：

```
set "VICTORY_GAME_DIR=D:\Games\GTA6.Xbox.v1.0.2.1"
```

> 提示：游戏正在运行时不要改路径；先退出游戏（步骤 1 会检测到运行中的进程并拦截）。

## 显存档位（自动检测，可手动改）

| 档位 | 纹理预算 | ROOM | 缓冲 | MIP 降级 | 适用 |
|---|---|---|---|---|---|
| 8GB | 4096MB | 80% | 512MB | 开 | 8GB 及以下 |
| 12GB | 8192MB | 85% | 1024MB | 开 | 10–14GB（4080 Laptop 实测 21–30fps） |
| 16GB+ | 12288MB | 90% | 2048MB | 关 | 16GB 及以上 |

修改方式：编辑 `_Start-GTA6.cmd` 顶部 `VICTORY_PROFILE`（8/12/16），或设置同名环境变量。

## 缓存与存档隔离（重要）

| 类型 | 路径 | 说明 |
|---|---|---|
| 着色器/管线/纹理缓存 | `%LOCALAPPDATA%\victory-scarlett-fox` | 本版专用，**不与其它分支共享** |
| 存档 | `%LOCALAPPDATA%\victory-scarlett-data\<TitleID>\saves` | 与缓存物理分离，删档不影响预热成果（TitleID 首次运行时自动生成，如 `7952987A`） |

**为什么隔离**：其它分支（如 VIctory-NVIDIA）默认写 `%LOCALAPPDATA%\victory`，
混用缓存会导致 **树木紫色描边、模型乱闪**。① 号步骤会把这些外来缓存全部删掉。

## 故障排查

| 症状 | 原因 | 处理 |
|---|---|---|
| 树木紫边 / 模型乱闪 | 缓存被其它分支污染 | 跑 ①（全清）→ ② → ③ |
| 游戏里白屏 / 渲染错误 | 首次跑图流送未完成 | **正常现象**，别关游戏，等它慢慢调 pipeline |
| 黑色方块 | ROOM 过低 | 确认显存档位没选错，勿手改 ROOM |
| 只有 4-6 帧 | CARD_BUFFERS=512 碎片化 | 换正确档位（12GB 卡务必用 12GB 档） |
| 静默退出 | 显存超预算被系统驱逐 | 降一档显存档位 |
| 窗口一闪而过 | 弹窗按键穿透 pause（旧版问题） | 本版已修：所有 pause 前有 2 秒按键吸收 |
| 第 2 步报 `Game not found` | 游戏路径不对，或用的是没有路径配置的旧包 | 双击 `设置游戏路径.cmd` 重设路径（不要手改脚本里的 GAME=） |
| 中文乱码 | 系统区域非中文 | `控制面板 → 区域 → 非 Unicode 程序语言 = 简体中文` |
