# GTA VI (Xbox) → PC 通用移植包（scarlett-fox）

> **下载**：[`scarlett-fox-通用-2611272152.zip`](./scarlett-fox-通用-2611272152.zip)（约 5 MB，解压即用）
> 分支：`Op-lite/victory-scarlett` @ `scarlett-fox`（含上游冻结修复、着色器预翻译、画面修复）
> 适配：**8GB / 12GB / 16GB+** NVIDIA 显卡，自动分档

---

## 这个包是什么

把 **Xbox 版 GTA VI（`GTA6.Xbox.v1.0.2.1` dump）** 通过 `victory` 兼容层在 Windows PC 上运行的整合包，包含：

- 自编译 `victory.exe`（上游最新源码，含冻结修复与画面修复）
- 5 个编号步骤脚本（选路径 → 检查清场 → 首次跑图 → 预热 → 日常启动）
- **多显存档位**（8/12/16GB+ 自动检测）
- **缓存/存档物理隔离**（杜绝跨分支污染导致的紫边、乱闪）
- 自有存档**备份/还原**（第 2 步备份，第 4 步自动还原）
- 10 分钟自动跑图看门狗、黑匣子日志、读秒可跳过

## 快速开始（5 步，按文件名数字顺序）

| 顺序 | 文件 | 作用 |
|---|---|---|
| ① | `1-设置游戏路径（运行一次就行）.cmd` | 弹窗选择游戏文件夹（含 `game_scarlett_master.exe`） |
| ② | `2-启动前检查（运行一次就行）.cmd` | 查进程 / 校验 exe / 彻底清缓存；**询问是否备份你的存档** |
| ③ | `3-第一次启动（运行一次就行）.cmd` | 装自由模式存档 → 翻译着色器 → 自动跑图 10 分钟（白屏/卡顿正常，勿手动关） |
| ④ | `4-预热着色器（运行一次就行）.cmd` | 预热全部管线 → 删除自由模式存档 → **自动还原你的存档**，缓存保留 |
| ⑤ | `5-正常启动（之后一直用这个启动）.cmd` | 日常启动 |

> 首次走 ①→⑤ 一遍；之后每天只双击 **⑤**。
> 紫边/乱闪 = 缓存污染，回到 ②③④ 重走即可。

## 显存档位（自动检测，可手动改）

| 档位 | 纹理预算 | ROOM | 缓冲 | MIP 降级 | 适用 |
|---|---|---|---|---|---|
| 8GB | 4096MB | 90% | 512MB | 开 | 8GB 及以下 |
| 12GB | 8192MB | 90% | 1024MB | 开 | 10–14GB |
| 16GB+ | 12288MB | 90% | 2048MB | 关 | 16GB 及以上 |

改档：编辑 `_Start-GTA6.cmd` 顶部 `VICTORY_PROFILE`（8/12/16），或设同名环境变量。

## 已知问题（上游未解决）

- 某些场景的紫斑可能残留几秒；角色身上偶见品红条纹（上游 README 有记录）
- 跑图阶段白屏、渲染错误、卡顿属正常流送现象
- 30fps 档位（`FRAME_INTERVAL_MS=33.3`），追求更高帧率需自行调整

## 故障排查

| 症状 | 处理 |
|---|---|
| 第 2 步报找不到游戏 | 运行 `1-设置游戏路径` 重选文件夹 |
| 树木紫边 / 模型乱闪 | 跑 ②（全清）→③→④ 重新预热 |
| 黑块 / 静默退出 | 降一档显存档位（如 16GB 档改 12GB） |
| 只有 4–6 帧 | 确认用了正确显存档位，勿手改缓冲 |
| 窗口秒关 | 本版已修；若仍出现，任务管理器结束残留 `cmd.exe` |
