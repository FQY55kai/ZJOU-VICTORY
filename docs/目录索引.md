### 调试环境变量速查

| 变量 | 作用 |
|---|---|
| `VICTORY_D3D12_DEBUG` | 启用 D3D12 debug layer，失败时附首条错误（命名命令） |
| `VICTORY_D3D12_DRED` | 自动面包屑 / 活动 list 报告（定位挂死命令） |
| `VICTORY_D3D12_WARP` | 软件适配器，避免真 GPU 挂死（极慢） |
| `VICTORY_GPU_TIMING` | 每个 list 单独提交并计时 |
| `VICTORY_CAPTURE` / `VICTORY_CAPTURE_FRAMES` | **仅 diagnostics 构建**写 present 帧 PNG |
| `VICTORY_SKIP_BREAKPOINTS` | 跳过 int3（workaround，非根治） |
| `XCL_MESH_AS_FALLBACK` | AS slot 中的 MS 容器当作 mesh shader |
| `XCL_SKIP_NULL_WRITES` / `XCL_SKIP_INT3` | 闪退 workaround |
| `XCL_TWO_PASS_EXEC` | 两阶段 mesh 执行（当前仍 miss，待修） |
| `XCL_FRAME_DUMP` | 内部帧 dump（cloaked 窗口 PrintWindow 只能抓白屏，须用此） |
