| 实际翻译 | 依赖后台队列，出现 skipped draws | 16,384 draws 全部 `0 skipped`，直译管线即用即译 | **draw 丢弃已消除** |
| 缓存产物 | — | 3054 个 `.dxil`（222 MB）+ `used-pipelines.txt`，最新 07:36 | 新缓存已成型 |

**结论（分三点）**：

1. **`Shader wants wave lane count of 64` 拒绝被彻底消除**——这是本次重建成效最明确的一项，split-wave64 让 64 lane 程序以两个 32 lane 半波执行，驱动不再拒收。
2. **翻译缺口（does not translate / skipped draws）在本次运行中为 0**，draws 全部命中已翻译管线。
3. **窗口标题里的 `57,176 pipelines queued` 是真实遗留**：计数停在 0 running / 0 done，说明该队列（后台预编译）已不再推进，但游戏靠 direct DXIL 按需翻译跑满 30 FPS，同时代价是**启动期加载慢**（sparse 上传 21.2 s/1024 提交，write-watch 单轮 9.8–23.5 s / 约 40 万脏页）。**这不影响画面，但影响首帧后到进世界的等待时间。**
